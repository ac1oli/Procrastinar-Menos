## Limitações identificadas
1. WSL2/Docker inoperantes até reiniciar o PC.
2. 16 GB de RAM é o principal gargalo: Docker/WSL2 + Laravel + PostgreSQL
   + dashboard + VS Code competem por memória. Recomenda-se limitar a
   memória do WSL2 (`.wslconfig`) após o reboot.
3. 8 GB de VRAM limitam os modelos a ~8B em Q4 com contexto moderado.
4. GPU AMD não é acessível de dentro de containers no Windows.
5. ~~Python 3.14 é muito recente~~ — **resolvido na FASE 2:** fastapi 0.163.1,
   pydantic 2.14.3, uvicorn, httpx, psycopg 3.3.9, pgvector, pytest e ruff
   instalam e importam normalmente no 3.14.7.
6. Windows em build Insider: atualizações podem alterar comportamento de WSL/drivers.
7. O PostgreSQL 16 nativo pré-existente escuta em `0.0.0.0:5432` (todas as
   interfaces). Não faz parte deste projeto; recomenda-se ao proprietário
   avaliar se essa exposição na rede local é intencional.
